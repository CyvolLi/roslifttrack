# Designbook — 设计方案 / 设计结构 / 设计标准

存放**设计阶段的思考成果**：方案文档、结构说明、团队统一的设计标准。

## 存放内容

| 类型 | 示例 |
|------|------|
| 设计方案 | 升降机构方案对比、选型论证、评审记录 |
| 设计结构说明 | 整体结构布局、模块划分、传动/承重说明 |
| 设计标准 | 公差标准、材料选用标准、标注规范、命名规范 |

## 目录组织

每个方案/主题一个文件夹：

```
designbook/
├── 01_升降方案/
│   ├── 方案说明.docx        # 方案文档
│   ├── 结构草图.png         # 示意图
│   └── 评审记录.md          # 评审结论与待办
├── 02_结构布局/
└── 00_设计标准/
    └── 设计标准_V1.0.docx   # 团队通用标准
```

## 文档要求

1. 每个方案必须有：**背景 / 方案说明 / 优缺点 / 结论** 四部分
2. 方案定稿后在评审记录里写明：评审人、评审日期、结论
3. 设计标准是团队的**共同约定**，修改需在 README 或记录中说明变更原因

## 命名规范

```
[编号]_[方案/标准名称]_[版本].后缀
```

示例：`01_升降方案_V1.0.docx`、`00_公差标准_V1.1.docx`

## 版本说明

- 方案文档：评审通过后升正式版本 `V1.0`
- 设计标准：小改升 `V1.x`，大改（影响所有设计）升 `V2.0`
- 废弃方案移入 `_废弃/` 文件夹，不直接删除（保留思路过程）
