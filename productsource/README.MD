# Productsource — 成品产品标准书

存放**外购成品**的产品标准书、规格书、选型资料，供团队统一查阅。

## 存放内容

| 类型 | 示例 |
|------|------|
| 外购成品标准书 | 电机、导轨、丝杆、传感器、标准件的规格书 |
| 选型手册 / 样本 | 厂商产品样本、选型表 |
| 采购信息 | 型号、厂商、关键参数、供货信息 |

## 目录组织

按部件类别分类：

```
productsource/
├── 电机/
│   └── 厂商A_电机型号X_规格书_V1.0.pdf
├── 导轨/
├── 传感器/
└── 标准件/
```

## 命名规范

```
[厂商]_[产品类别]_[型号]_[版本].后缀
```

示例：`厂商A_导轨_HGR15_规格书_V1.0.pdf`

## 重要规则

1. **原厂资料只读**：禁止修改原厂 PDF/图纸内容
2. 拿到新版资料时**新增文件并升版本**，不要覆盖旧版（方便追溯选型依据）
3. 每份资料建议在文件名或内容里标注：**厂商 / 型号 / 获取日期 / 供货渠道**
4. 选型引用时，在 `designbook` 的设计方案中写明用了哪个型号、依据哪份标准书
5. 有国产替代或备选方案时，单独放一份说明文档，不直接改原厂资料

## 提交检查清单

- [ ] 文件为原厂原版资料（或清晰扫描件）
- [ ] 命名含厂商、类别、型号
- [ ] 与设计选用型号一致，没有混淆
